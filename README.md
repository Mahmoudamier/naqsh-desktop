# نقش — برنامج سطح مكتب حديث

أداة Windows أصلية (مش موقع) لكتابة عربي/لغات تانية على الصور، بواجهة **CustomTkinter** داكنة وسريعة.

## الواجهة الجديدة

- **شريط أدوات علوي:** افتح صورة، الصق، احفظ PNG (نافذة اختيار مكان)، **Save** (لون أزرق بارز — يحفظ مباشرة على سطح المكتب باسم فيه تاريخ ووقت)، قص الصورة، رجّع الافتراضي، اختصارات، تبديل الثيم، وتكبير/ملاءمة المعاينة.
- **لوحة يمنى نظيفة:** كروت مرتّبة — الكلام واللغة / الخط والمقاس / المكان والتحريك / إعدادات زيادة.
- **ثيم داكن موحّد:** الخلفية `#121212`، اللوحة `#1E1E1E`، الحقول والقوائم `#2A2A2A`، الحدود `#3A3A3A`، النص `#FFFFFF`. فيه كمان ثيم نهاري بالزر ◐.

## التفاعل على اللوحة

- **مقابض تحكم مباشرة:** 8 مقابض (4 أركان + 4 أطراف) حوالين الكلام؛ اسحب أي واحد لتغيير المقاس في الوقت الفعلي مع تثبيت النقطة المقابلة (زي فوتوشوب).
- **عجلة الفارة:** `Ctrl + عجلة` في أي مكان على اللوحة يغيّر مقاس الكلام. الـ wheel العادي بيغيّر المقاس لما تكون فوق الكلام، وبيكبّر المعاينة برّه.
- **مقاس دقيق:** سلider + خانة رقمية تكتب فيها الرقم أو بالأسهم `↑ / ↓`.
- **سحب سلس:** الصورة والنص طبقتان منفصلتان، والأسهم بتحرّك بالحبة و`Home` بيوسّط.
- **`Ctrl + V` عالمي:** يلصق صورة من الحافظة فوراً، ولو مفيش صورة يلصق النص جوّه مربع الكلام.

## الخط والعربية

- خطوط عربية مضمّنة: **Baloo Bhaijaan 2 (الافتراضي)**، Cairo، Tajawal، Amiri، Noto Sans Arabic، Noto Naskh Arabic، Almarai، IBM Plex Sans Arabic. ملف الخط المتغير بيحتوي على Regular وBold جوّه ملف واحد، والرخصة `fonts\OFL-BalooBhaijaan2.txt`.
- تنقّل بالأسهم `↑ / ↓` في قائمة الخطوط مع معاينة حيّة لكل خط على اللوحة.
- تشكيل كامل (ligatures + الحركات + بيدي RTL) في المعاينة وملف PNG النهائي.
- لغات: العربية، English، Français، Español، Deutsch، Português، Italiano، Русский، 中文.

### إصلاح عرض العربية (Tofu / الحروف المقطوعة)

- المشكلة كانت إن `arabic_reshaper` بيخرج حروف بصيغة **Arabic Presentation Forms** (`U+FE70–U+FEFF`)، وخطوط Cairo/Tajawal/Almarai في ملفاتها الأصلية **مفيهاش النماذج دي في الـ cmap**، فكان FreeType بيرسم مربعات فاضية بدل الحروف.
- اتصلّحت ملفات الخطوط نفسها بإضافة الـ Presentation Forms المشتقة من جدول GSUB لكل الأوزان (Regular/Bold) — وكمان `BalooBhaijaan2.ttf` (114 صيغة مضافة)، والنسخ الأصلية للخطوط القديمة محفوظة في `fonts_original_backup\`.
- مسار المعالجة الموحّد قبل أي رسم أو حفظ (في `App.shape_text()` ويُستخدم في `wrap()` و`rebuild_overlay()`):
  ```python
  reshaped_text = arabic_reshaper.reshape(raw_text)   # ربط الحروف + التشكيل
  bidi_text     = get_display(reshaped_text)          # اتجاه RTL
  draw.text(..., bidi_text, font=font)                 # الرسم النهائي
  ```
- لو أي ملف خط افتقد أو اتلف، فحص تلقائي بيكتشف غياب النماذج ويستبدل الخط بـ `Noto Sans Arabic` عشان الكلام يفضل مقروء. كل النصوص UTF-8 (`# -*- coding: utf-8 -*-`).

## القص والاختصارات

- زر «قص الصورة» → اسحب مستطيل → `Enter` أو «تم» للتأكيد، `Esc` أو «إلغاء» للإلغاء.
- `Ctrl+O` افتح • `Ctrl+S` احفظ • `Ctrl+A` تحديد كل الكلام • `Ctrl+V` الصق • `Ctrl++/-` المقاس • `Ctrl+0` ملاءمة • `Home` توسيط.

## الملفات

- `app.py` — المصدر كله.
- `build.ps1` — يبني الـ exe ويحدّث نسخة سطح المكتب `نقش.exe`.
- `dist\NaqshDesktop.exe` — النسخة المبنية.
- `fonts\`, `logo.ico` — أصول مضمّنة.

## التطوير

```powershell
python app.py
powershell -ExecutionPolicy Bypass -File build.ps1
```

الحزم: `customtkinter`، `pillow`، `arabic-reshaper`، `python-bidi`، `tkinterdnd2`، `pyinstaller`.
